# Contributing to RCE-Lab

Thank you for your interest in contributing to **RCE-Lab**! Whether it's reporting a bug, adding a new challenge level, or improving documentation, contributions are warmly welcomed.

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch** (`git checkout -b feature/amazing-level`)
3. **Commit Your Changes** (`git commit -m 'Add Level 11: Prototype Pollution RCE'`)
4. **Push to the Branch** (`git push origin feature/amazing-level`)
5. **Open a Pull Request**

## Guidelines
- Ensure any new lab levels include clear source code inspection views and educational descriptions.
- Adhere to the existing design system (CSS variables, card badges, responsive grid).
- Maintain strict educational safety and ethical standards.
